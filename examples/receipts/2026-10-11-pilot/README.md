# Exploratory receipts from 11 October 2026

These are public summaries of thirty protocol 0.1 pilot attempts, not complete
transcripts. They retain model/backend identifiers, request settings, hashes,
timing, tool diagnostics, checks, and stop reasons. The private conversation
and tool event traces were omitted from this public repository.

The pilot task `arkade-add` used a fictional CLI and is **not** the real shfmt
task in the current suite. Thinking settings also differ between models; these
cards are examples of diagnostic receipts, not a model or quantisation
leaderboard. The PDF task was not part of these matched pilot cards.
